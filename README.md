# Push_swap Project 🚀

## Description
The `push_swap` project is a sorting algorithm challenge where the goal is to sort a stack of integers using a limited set of operations. This project demonstrates my ability to implement efficient algorithms in C while adhering to strict coding standards. 📊

## Features
- Efficient sorting of integers using two stacks.
- Minimal number of operations to achieve the sorted order.
- Error handling for invalid inputs.
- Bonus checker program to validate sorting operations.

## How It Works
The program utilizes two stacks (`a` and `b`) and implements a series of operations to sort the integers in stack `a` in ascending order. The main algorithm focuses on minimizing the number of operations required to achieve the sorted state. 

## Operations
The following operations are implemented:

- `sa`: Swap the first two elements of stack `a`. 🔄
- `sb`: Swap the first two elements of stack `b`. 🔄
- `ss`: `sa` and `sb` at the same time. 🔄🔄
- `pa`: Push the top element of stack `b` onto stack `a`. ⬆️
- `pb`: Push the top element of stack `a` onto stack `b`. ⬇️
- `ra`: Rotate stack `a` upwards. 🔁
- `rb`: Rotate stack `b` upwards. 🔁
- `rr`: `ra` and `rb` at the same time. 🔁🔁
- `rra`: Reverse rotate stack `a`. 🔙
- `rrb`: Reverse rotate stack `b`. 🔙
- `rrr`: `rra` and `rrb` at the same time. 🔙🔙

## Benchmarking
To validate the efficiency of the sorting algorithm:
- Successfully sorted 100 random numbers in fewer than 700 operations. 🏆
- Sorted 500 random numbers in no more than 5500 operations. 🥇

## Usage
To run the `push_swap` program, use the following command:
```bash
./push_swap <list_of_integers>
```

Example:
```bash
./push_swap 8 7 2 0 1 22
```

To check the operations generated:

```bash
ARG="4 67 3 87 23"; ./push_swap $ARG | ./checker_linux $ARG
```

## Bonus Part
A checker program is included to verify if the list of operations generated by push_swap correctly sorts the stack. This part ensures that the operations are valid and the final stack is sorted. 🎉
